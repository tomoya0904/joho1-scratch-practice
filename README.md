# ブロックでわかるプログラミング — 学習ノート p.54–55

高校「情報Ⅰ」の学習ノート p.54〜55、PRACTICE 1〜4に対応したScratch風の学習サイトです。

## 授業での使い方

1. `index.html` をブラウザで開き、PRACTICE を選びます。
2. 各STEPの「1行ずつ」で変数と表示の変化を観察します。
3. 左側の小問に答え、「答えをチェック」で確認します。
4. 正解後に「次のステップ」で、学習ノートの本番問題まで進めます。
5. ブロックの白い入力欄や選択欄を変えて、実行結果を実験できます。
6. ブロックの「↑」「↓」「×」で並べ替え・削除、下のボタンで追加できます。PCでは追加ボタンからドラッグも可能です。

学習の進捗は、対応ブラウザの場合、その端末内（localStorage）だけに保存されます。入力データの送信はありません。

## GitHub Pages で公開する方法

1. GitHubにログインして `New repository` を選びます。例: `joho1-programming-practice`。
2. **Public** でリポジトリを作ります（GitHubのプランによってはPrivateでもPagesを利用できます）。
3. リポジトリ最上位に `index.html` をアップロードしてコミットします。`README.md` と `.nojekyll` は任意ですが、一緒に置くと管理しやすくなります。
4. **Settings → Pages → Build and deployment → Source** で **Deploy from a branch** を選びます。
5. Branch は `main`、フォルダは `/(root)` を指定して **Save** します。
6. 公開が反映されたら、`https://<GitHubユーザー名>.github.io/<リポジトリ名>/` にアクセスします（反映まで数分程度かかることがあります）。

パスを含めて**外部URL参照が不要な単独のHTML**のため、ローカル・GitHub Pagesの両方で同じように動きます。
